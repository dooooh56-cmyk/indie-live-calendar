# 혼자살림

혼자 사는 사람을 위한 납부일·집안일·식재료 달력 MVP입니다. TypeScript, React, Vite로 만들었습니다.

## 실행

Node.js 22.22.2 이상(22.x), 24.15.0 이상(24.x), 또는 26 이상과 npm이 필요합니다.

```sh
npm install
npm run dev
```

표시되는 로컬 주소를 브라우저에서 열어 사용합니다. `npm test`로 반복 계산과 검증을 확인하고 `npm run build`로 타입 검사와 배포 파일 생성을 실행합니다.

일정과 완료 상태는 브라우저의 로컬 저장소에만 보관됩니다. 브라우저 데이터 삭제 시 사라지고 다른 기기로 동기화되지 않습니다. 알림은 권한을 허용하고 앱을 열어 둔 동안 해당 시각에 표시를 시도합니다. 백그라운드 탭의 실행 지연, 브라우저 종료, 기기 잠금 등으로 알림을 놓칠 수 있습니다. 반복 일정 수정은 전체 일정에 적용되며, 삭제는 전체 또는 선택한 날짜만 선택할 수 있습니다.

| **(3~6개월)** | **세탁기 통세척** | 세탁조 클리너 넣고 무세제 통세척 코스 돌리기 |

# 🏠 Chore Presets & Categories Reference for App Development

본 문서는 자취생 달력/일정 관리 앱 내 **"초기 집안일 프리셋(Chore Presets) 선택 탭"** 기능 구현을 위한 템플릿 데이터 가이드입니다.

---

## 📱 UI/UX Preset Selection Architecture

### 1. 카테고리 구조 (Category System)
- **주방 (Kitchen)**: 식사 관련 cleanup, 음식물 쓰레기, 위생 관리
- **욕실 (Bathroom)**: 물때, 곰팡이, 배수구 관리
- **방/거실 (Living Space)**: 바닥 먼지, 환기, 창틀, 쓰레기 배출
- **세탁/의류 (Laundry)**: 빨래, 침구류, 옷장 및 제습 관리
- **가전/정기점검 (Maintenance)**: 세탁조, 에어컨 필터, 소모품 교체

### 2. 난이도/자취 유형 필터 (Preset Packages)
- 🐣 **초보 자취러 패키지 (Essential)**: 필수 집안일 최소 세트 (주 5개 내외)
- 🌿 **꼼꼼 자취러 패키지 (Detailed)**: 주기적 딥클리닝 및 정기 점검 포함
- ⚡ **최소주의 패키지 (Minimalist)**: 설거지/빨래/쓰레기 배출 위주
